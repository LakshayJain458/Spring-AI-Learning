# 🤖 Spring AI — Learning Journey

> A hands-on practice repository documenting my deep dive into **Spring AI** — building intelligent, production-style systems using the Java & Spring ecosystem.

---

## 📖 About

This repository contains all the code, experiments, and mini-projects I built while completing a full **Spring AI** series.

The goal wasn't just to understand the concepts — it was to implement them. Every topic here has working code behind it.

---

## 🧠 What I Learned & Built

### ✅ Spring AI Fundamentals & Architecture
Core building blocks of Spring AI — how it abstracts LLM providers, manages prompts, and integrates seamlessly with the Spring Boot ecosystem.

### ✅ RAG — Retrieval-Augmented Generation Pipeline
Built a full RAG pipeline that makes AI responses context-aware by retrieving relevant documents before generating answers. No more hallucinations from thin air.

### ✅ ETL Pipeline
Designed an Extract-Transform-Load pipeline to ingest, chunk, and store documents for AI retrieval — the backbone of any knowledge-grounded AI system.

### ✅ Vector Database Integration
Integrated a Vector DB for semantic search — moving beyond keyword matching to meaning-based retrieval.

### ✅ AI Tool Calling & Conversational Memory
Enabled AI to call real functions and remember past interactions — turning a stateless LLM into a stateful, action-capable assistant.

### ✅ MCP — Model Context Protocol
Explored MCP, the emerging standard for connecting AI models to real-world tools and external data sources in a structured, scalable way.

### ✅ Weather Agent
Built a small but functional AI agent that fetches live weather data and reasons over it to answer user queries — a practical introduction to agentic AI patterns.
